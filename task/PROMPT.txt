为内部安全分类词表实现版本迁移校验器。版本中每个标签对应不可重复的原子敏感类别集合，标签间允许重叠。新版本可拆分、改名或合并标签，只能通过显式候选映射把旧标签替换为一组新标签。对象原有效敏感集合取其旧标签的并集，迁移期新消费者与旧消费者可分别操作对象。每个角色声明可读的原子类别集合，且仅在对象有效分类是它的子集时允许读取。映射转换后对象的分类不能漏标，也不能给任何输入登记的角色改变对任一对象的允许结论。允许超标，但在满足安全与兼容前提下最小化所有对象上额外类别数总和。一个旧标签在所有对象上用同一映射，不能逐对象选。
plan 先最小化总额外类别数，再最小化所有映射中使用的新标签个数（同一新标签在不同旧标签的映射中分别计），最后按旧、再新标签 ID 决胜。audit 对既定方案逐对象逐角色核对并给最小可观测反例，update 在 SQLite 内按词表版本和对象版本原子切换，切换后保留旧版本的历史判定。支持 16 个旧标签、每个至多 3 种候选映射，说明复用掩码和剪枝。测试至少包含两个旧标签引入同一额外类别时在同一对象上只计一次代价、角色没有授权导致额外类别不能加、已改名但语义完全一致、无解、过期计划及故障后重启。

使用 Windows 原生 Python 3.12、标准库和 CPU，从空仓库实现，所有夹具用本地虚构数据。命令格式为 python -m solution <命令> CASE.json，涉及持久状态的命令带 --db DB.sqlite。标准输出为 UTF-8 JSON，同一逻辑输入产生同一结果；结构错误给出可定位的错误码及字段位置。交付可直接运行的样例、README（含完整输入输出定义与复现命令）和可用 python -m unittest discover -s tests -v 执行的断言测试。
